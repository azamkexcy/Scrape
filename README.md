# 📦 Public Database & Web Scrape Repository

Repository ini berisi **database hasil scrape dari web** serta **script pendukung** yang dapat digunakan oleh publik.  
Tujuan utama repo ini adalah menyediakan data, hasil ekstraksi, dan alat bantu yang dapat digunakan untuk penelitian, integrasi aplikasi, atau kebutuhan publik lainnya.

---

## 📁 Isi Repository

### **1. /database**
Folder ini berisi berbagai kumpulan data hasil scraping dari berbagai sumber web.


Contoh isi:
- `users.json` — Data pengguna hasil scraping
- `articles.csv` — Artikel atau postingan publik
- `metadata.json` — Informasi tambahan atau hasil ekstraksi

> Semua data bersifat publik (public data source). Tidak mengandung informasi sensitif atau pribadi.

---

### **2. /scripts**
Berisi berbagai script yang digunakan untuk:
- Melakukan scraping data
- Membersihkan/memformat hasil scrape
- Mengubah data menjadi format lain
- Automasi kecil lain terkait data

Format script:
- JavaScript / TypeScript
- Python
- Shell Script

Contoh isi:
- `scrape.js` — Script untuk mengambil data dari situs tertentu
- `convert.py` — Mengubah data menjadi format CSV atau JSON
- `cleaner.ts` — Membersihkan format data hasil scraping
